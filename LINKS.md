## 🚦 Verification / QA tools

### Live URL health checks (from terminal)
```bash
# Quick "is the page live" check
curl -I https://www.aura.today/blog-post/best-rose-toys-2026

# Extract tab title from raw HTML
curl -s https://www.aura.today/blog-post/best-rose-toys-2026 | grep -oE '<title>[^<]*</title>'

# Cache-buster URL (force fresh fetch)
curl -s "https://www.aura.today/blog-post/best-rose-toys-2026?v=$(date +%s)"
```

### Browser cache-bust shortcuts
- **Hard refresh**: `Ctrl+Shift+R` (Windows/Linux) or `Cmd+Shift+R` (Mac)
- **Incognito**: `Ctrl+Shift+N` (Chrome) — fresh cache, no extensions
- **DevTools "Disable cache"**: open DevTools → Network tab → check "Disable cache" while DevTools is open

Per the Meta Ad Compliance Audit in the original session plan, this product category is **banned on Meta** and Google Search Ads. Viable paid channels:

- **Pinterest**: [pinterest.com/business](https://www.pinterest.com/business/) — most permissive for "wellness" framing, vertical pin format matches your hero photos
- **Reddit Ads**: [ads.reddit.com](https://ads.reddit.com/) — NSFW subreddit ads or r/wellness allowed
- **X (Twitter) Ads**: [ads.x.com](https://ads.x.com/) — more permissive than Meta
- **ExoClick**: [exoclick.com](https://www.exoclick.com/) — adult-friendly ad network
- **TrafficJunky**: [trafficjunky.com](https://www.trafficjunky.com/) — adult-friendly ad network
- **JuicyAds**: [juicyads.com](https://www.juicyads.com/) — adult-friendly ad network

DON'T spend on:
- Facebook / Instagram ads (banned category — account ban risk)
